# college

Archive of some projects from college.

- **FormalMethods_TypeChecker** (Formal methods) — Type checker implemented in OCaml.
- **lftc** (Formal languages and compiler techniques) — Finite automata, lexical analysis, parsing, and compiler exercises in C#, C/C++, Flex, and Bison. 
- **metsoftproc** — Control-flow graphs and dataflow analysis in OCaml.
- **numcalc** (Numerical calculus) — Numerical methods exercises in MATLAB, including interpolation, linear systems, and numerical integration.
